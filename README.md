# Белый кот — демонстрационный сайт

**Независимый неофициальный концепт** для сервиса стирки ковров и химчистки мебели в Вологде и Череповце. Разработчик: [@milmak11](https://t.me/milmak11).

## Что внутри

- Оригинальный адаптивный дизайн (от 320 px), без тяжёлых рамок и декоративной нумерации разделов.
- Авторский SVG-логотип кота, более 9 самостоятельных SVG-сцен и набор SVG-иконок.
- Плавные анимации появления, hover-переходы, поддержка `prefers-reduced-motion`.
- Выбор города (Вологда / Череповец) с синхронизацией в формах.
- **Калькулятор ковров**: до 8 различных позиций, длина и ширина, количество, ворс, загрязнения, запрос на забор и доставку. Расчёт общей площади и подготовка подробного запроса.
- **Заявка на химчистку мебели**: изделие, вид загрязнения, комментарий, локальный предпросмотр фотографии JPG / PNG / WebP до 8 МБ.
- **Интерактивный слайдер «до / после»** и три варианта рисунка ковра. Это стилизованные иллюстрации, НЕ реальные фотографии выполненных работ.
- Этапы доставки, блок о компании, FAQ, ссылки на сообщество и контакт основателя VK.
- Аккуратная рамка «Разработчик @milmak11» в футере.

## Как открыть и проверить

Откройте **`preview-offline.html`** двойным нажатием: это полностью автономная версия сайта со встроенными SVG, CSS и JavaScript. В ней работают формы и интерактивные элементы, включая копирование текста при наличии разрешения браузера. Никакой установки не требуется.

Для просмотра оригинальных исходников можно открыть `index.html` напрямую или запустить локальный сервер:

```bash
python3 -m http.server 8000
```

Перейдите на `http://localhost:8000`.

## Как опубликовать на Vercel

Проект **статический (HTML/CSS/JS), без npm и зависимостей**. Это сделано намеренно, чтобы сайт быстро загружался и разворачивался на Vercel без сборки.

1. Распакуйте ZIP.
2. Загрузите файлы из `Belyy_Kot_Website_Vercel` в GitHub-репозиторий (чтобы `index.html` находился в корне репозитория).
3. В Vercel нажмите **Add New → Project**, импортируйте репозиторий.
4. Выберите **Framework Preset: Other**. Build Command оставьте пустой / отключённой, Output Directory не указывайте — сайт находится в корне проекта.
5. Выполните Deploy. Подберите домен, например `belyy-kot35-demo.vercel.app`, если свободен.

Поскольку `index.html` находится в корне, стандартный статический деплой не требует дополнительных настроек.

## Перед передачей владельцу

- Подтвердить действующие телефоны, физические адреса, границы зон обслуживания и расписание по обоим городам.
- Получить актуальную цену за м², минимальный заказ и условия доставки; при желании добавить расчёт суммы в калькулятор.
- Подтвердить виды принимаемых ковров и мебели, реальные сроки и условия гарантии.
- С согласия владельца добавить собственные фотографии работ и реальные отзывы с корректным указанием источников.
- Подключить реальную форму заявок, домен и согласовать обработку персональных данных.
- Удалить пометку «Неофициальный концепт» и настройки `noindex` **только после получения разрешения компании**.

В текущей версии **нет отправки заявок на сервер**, нет аналитики и базы данных. Калькулятор не показывает выдуманные тарифы. Изображения и маскот являются авторскими иллюстрациями, а не фотографиями сотрудников, автотранспорта или цеха компании. Фотография мебели остаётся в браузере пользователя; функция «Скопировать» копирует лишь текст заявки.

## Проверка

Проверены экраны 320, 390, 820, 1440 px в Chromium; горизонтальной прокрутки нет. Проверены логика нескольких ковров (включая расчёт 6 + 16 = 22 м²), валидация неверных размеров, смена города, копирование текстов заявок, переключение иллюстративных примеров, загрузка/удаление локального предпросмотра фото, FAQ и мобильное меню. Ошибок JavaScript в браузерной проверке не выявлено.
